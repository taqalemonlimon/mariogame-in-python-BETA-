┌─────────────────────────────────────────────────────────────────────────┐
│ ✨ НОВЫЕ ФИЧИ / NEW FEATURES                                            │
└─────────────────────────────────────────────────────────────────────────┘

1. СИСТЕМА ЖИЗНЕЙ
   + Марио начинает с 3 жизней
   + Отображение текущего количества жизней в UI
   + При потере всех жизней - GAME OVER

2. ЧАСТИЦЫ (PARTICLE EFFECTS)
   + При сборе монеты - золотые частицы разлетаются в стороны
   + При поражении врага - красные частицы взрыва
   + Красивая анимация за сборку монет и врагов

3. УЛУЧШЕННЫЙ ИНТЕРФЕЙС
   + Больше информации на экране (уровень, очки, жизни)
   + Красивые шрифты и выравнивание
   + Явные экраны WIN и GAME OVER
   + Вывод финального счета

4. ПЕРЕЗАГРУЗКА ИГРЫ
   + Нажмите R для перезагрузки после GAME OVER или WIN
   + Счет обнуляется, жизни восстанавливаются
   + Стартуете с уровня 1

5. УЛУЧШЕННЫЕ РАЗМЕРЫ
   + Окно расширено с 800x600 до 1000x600
   + Больше пространства для геймплея
   + Лучше видимость всех элементов

6. УЛУЧШЕННАЯ ВИЗУАЛИЗАЦИЯ
   + Более четкие изображения врагов
   + Лучшие переходы между уровнями
   + Более информативный UI

7. ЛУЧШАЯ AI ВРАГОВ
   + Враги умеют определять края платформ
   + Враги разворачиваются при касании стен
   + Более реалистичное поведение

ВАРИАНТ 1: ЗАПУСТИТЬ PYTHON ВЕРСИЮ
───────────────────────────────────
1. Установить Python: https://www.python.org/
   (отметить "Add Python to PATH")

2. Запустить: INSTALL_DEPENDENCIES.bat

3. Запустить: super_mario_game.py

ВАРИАНТ 2: СОЗДАТЬ .EXE ФАЙЛ
────────────────────────────
1. Установить Python (см выше)

2. Запустить: BUILD_EXE.bat

3. Найти: dist\SuperMario.exe

4. Готово! Можно отправлять друзьям

Клавиши управления / Keyboard Controls:
─────────────────────────────────────────
→  / D       - Движение вправо / Move Right
←  / A       - Движение влево / Move Left
↑  / W / SPC - Прыжок / Jump
R            - Перезагрузить / Restart

Советы:
───────
1. Собирайте монеты = +100 очков
2. Прыгайте на врагов сверху = +200 очков
3. Избегайте шипов = смертельно!
4. Достигните флага = следующий уровень
5. Всего 3 уровня
