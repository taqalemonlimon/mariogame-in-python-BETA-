## 🚀 Быстрый старт / Quick Start

### Способ 1: Запустить Python скрипт напрямую (для тестирования)

1. **Установите Python 3.7+** с https://www.python.org/
   - Важно: Отметьте "Add Python to PATH"

2. **Установите зависимости:**
```bash
pip install pygame
```

3. **Запустите игру:**
```bash
python super_mario_game.py
```

### Способ 2: Создать .EXE файл (для распределения)

#### Автоматический способ (Рекомендуется):

1. **Двойной клик по файлу `BUILD_EXE.bat`**
   
   Или в Command Prompt (CMD):
   ```bash
   BUILD_EXE.bat
   ```

2. Скрипт автоматически установит необходимые пакеты и создаст `SuperMario.exe`

3. Найти EXE в папке `dist/SuperMario.exe`

#### Ручной способ:

1. **Установите PyInstaller:**
```bash
pip install pyinstaller
```

2. **Выполните команду (используйте ; вместо \ на Linux/Mac):**
```bash
pyinstaller --onefile --windowed --name "SuperMario" --icon "logo.ico" ^
    --add-data "MARIO.png:." --add-data "block.png:." ^
    --add-data "coin.png:." --add-data "monster.png:." ^
    --add-data "cloude.png:." --add-data "AHHH.png:." ^
    --add-data "nintendo.png:." --add-data "logo.ico:." ^
    super_mario_game.py
```

3. EXE будет находиться в папке `dist/`

## 🎮 Советы по прохождению / Game Tips

1. **Собирайте монеты** - каждая дает +100 очков
2. **Прыгайте на врагов** - дает +200 очков (враги исчезают)
3. **Избегайте шипов** - они всегда смертельны
4. **Достигните флага** - переход на следующий уровень
5. **3 уровня** - всего 3 полных уровня с врагами и препятствиями

### Враги / Enemies:
- **Гумба (Гумба)**: Ходит по платформам, можно раздавить сверху
- **Шипы (AHHH.png)**: Движущиеся вверх-вниз шипы - избегайте!

## 🐛 Решение проблем / Troubleshooting

### Проблема: "Python is not installed"
**Решение:** Установите Python с https://www.python.org/ и отметьте "Add Python to PATH"

### Проблема: "pygame not found"
**Решение:** Выполните `pip install pygame`

### Проблема: "Image files not found"
**Решение:** Убедитесь, что все .png и .ico файлы находятся в той же папке, что и скрипт

### Проблема: EXE запускается но краш
**Решение:** Используйте BUILD_EXE.bat для пересборки, он правильно добавит все файлы

### Проблема: Лагает/медленно работает
**Решение:** Закройте другие приложения, обновите драйверы видеокарты

## 📚 Дополнительная информация / Additional Info

### Как работает BUILD_EXE.bat:

1. Проверяет наличие Python
2. Проверяет/устанавливает PyInstaller
3. Проверяет/устанавливает pygame
4. Создает EXE с использованием PyInstaller
5. Включает все графические ресурсы в EXE
6. Результат: `dist/SuperMario.exe` (готовый к распределению)

### Размер EXE:
- ~150-200 MB (один файл, все включено)
- Не требует установки
- Готов к запуску на любом Windows

### Как поделиться игрой:
1. Отправьте файл `dist/SuperMario.exe`
2. Получатель может запустить его напрямую
3. Не нужно ничего устанавливать!

## 🎨 Настройка игры / Game Configuration

Для изменения параметров игры, отредактируйте в файле `super_mario_game.py`:

```python
# Размер окна
SCREEN_WIDTH = 1000
SCREEN_HEIGHT = 600

# Скорость Марио
speed = 5.5

# Сила прыжка
jump_power = -14

# Гравитация
gravity = 0.6

# FPS (кадры в секунду)
FPS = 60
```
