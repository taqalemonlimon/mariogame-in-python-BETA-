=== БЫСТРАЯ УСТАНОВКА (5 минут) ===

ВАРИАНТ 1: Играть сразу (Python):
────────────────────────────────────
1. Установить Python: https://www.python.org/ 
   (обязательно отметить "Add Python to PATH")

2. Двойной клик: INSTALL_DEPENDENCIES.bat
   (установит pygame)

3. Двойной клик: super_mario_game.py
   ИЛИ в CMD: python super_mario_game.py

✓ ИГРА ЗАПУСТИТСЯ!


ВАРИАНТ 2: Создать EXE (для раздачи):
──────────────────────────────────────
1. Установить Python (см выше)

2. Двойной клик: BUILD_EXE.bat
   (займет 1-2 минуты)

3. Готовый файл: dist\SuperMario.exe

✓ Можно отправлять друзьям, не нужен Python!

=== УПРАВЛЕНИЕ ===

→ / D         : Движение вправо
← / A         : Движение влево  
SPACE / UP / W: Прыжок
R             : Перезагрузить игру


=== ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ ===

"Python is not installed":
  → Установите Python с https://www.python.org/
  → Отметьте "Add Python to PATH"

"pygame not found":
  → Запустите INSTALL_DEPENDENCIES.bat

"Картинки не загружаются":
  → Убедитесь что все .png файлы в папке с игрой

"BUILD_EXE.bat не работает":
  → Запустите INSTALL_DEPENDENCIES.bat сначала

=== СОВЕТЫ ПО ПРОХОЖДЕНИЮ ===

1. Собирайте монеты (+100 очков)
2. Прыгайте на врагов сверху (+200 очков)
3. Избегайте шипов (смертельно!)
4. 3 уровня всего
5. Достигните флага для перехода
